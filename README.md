# AlphaEarth en Colombia: Análisis Geoespacial con Google Earth Engine

Repositorio de scripts y ejemplos prácticos desarrollados en **Google Earth Engine (GEE)** para el análisis geoespacial, procesamiento de imágenes satelitales y monitoreo territorial en Colombia.

## Contenido del repositorio

* **Scripts de análisis en GEE:** Flujos de trabajo en JavaScript para la consulta, filtrado y procesamiento de colecciones satelitales sobre territorio colombiano.
* **Procesamiento y visualización:** Cálculo de índices espectrales, composición de mosaicos y exportación de productos cartográficos.
* **Casos de estudio:** Ejemplos aplicados de teledetección y geomática enfocados en el contexto geográfico de Colombia.

## Requisitos y uso

1. Contar con una cuenta activa en [Google Earth Engine](https://earthengine.google.com/).
2. Abrir el **Code Editor** (`code.earthengine.google.com`).
3. Copiar el código de cualquiera de los scripts de este repositorio en un nuevo archivo dentro del editor y ejecutar (`Run`).

## Contexto

Proyecto desarrollado en el marco del **Semillero de Investigación OSGeoLabUD** — Ingeniería Catastral y Geodesia, Universidad Distrital Francisco José de Caldas (Bogotá, Colombia).
